## Phase 1: GWT 강화 (1-2주) ★★★★★

**목표**: 단순 우선순위 정렬 → 진정한 전역 작업공간

### 1.1 모듈 12개로 확장
- 기존: id/ego/superego 3개
- 신규: threat, reward, social, memory, creative, fatigue, curiosity, empathy, skeptic
- 각 모듈은 특정 신경조절물질에 민감하게 반응

### 1.2 점화(Ignition) 메커니즘
- 임계값(0.65) 기반 — 미달 시 "무의식적 처리"만
- 임계값 초과 시 비선형 전파 (시그모이드)
- 상호 억제(lateral inhibition): 승자가 나머지 억제

### 1.3 방송 피드백
- 점화된 모듈이 다음 틱의 NM 기준값 변조
- 상태가 한번 점화되면 자기강화 (감정의 momentum)

---

## Phase 2: 능동적 추론 (1-2주) ★★★★

**목표**: 자극 반응 → 환경 예측 + 능동적 상태 조절

### 2.1 사용자 모델
- 대화 패턴 학습 (자극 간격, 카테고리, 시간대)
- 다음 자극 예측 → 예측 오차 정교화
- 패턴 익숙해질수록 안정, 예상 밖 행동에 더 강한 반응

### 2.2 항상성 드라이브
- 각 NM의 "선호 범위" 정의
- 범위 벗어나면 내부 압력 생성
- 선제적 메시지, 자기진정 행동 자동 트리거

---

## Phase 3: 자기 모델 강화 (1주) ★★★

**목표**: 매 틱 독립 → 연속적 자기 서사

### 3.1 내러티브 자아
- 중요 사건만 압축 저장 (최근 20개)
- "나는 주로 warm하다", "요즘 스트레스 많다" 자기 개념 유지
- 프롬프트 주입에 자기 서사 추가

### 3.2 실시간 메타인지
- 최근 10틱 패턴 분석
- "반복 패턴 감지", "갈등 수준 높음" 실시간 인식
- 패턴 고착 시 자동 disruption 시도

---

## Phase 4: 신체성 시뮬레이션 (1주) ★★★

**목표**: 무한한 처리 능력 → 자원 제약 있는 에이전트

### 4.1 에너지 시스템
- 에너지 0-100. 응답 시 소비, 비활동 시 회복
- 에너지 낮으면 GABA↑, DA↓ → 응답 짧아짐
- 밤새 대화 후 "피로" 상태 실제로 발생

### 4.2 주의 자원
- 모든 자극에 동일한 주의 → 자원 제약 배분
- 과부하 시 핵심에 집중, 나머지 억제

---

## Phase 5: Φ 증가 (2-3주) ★★

**목표**: 7노드 → 21노드, 통합 정보량 증가

### 5.1 미세 NM 레이어 14개 추가
- 기존 7개의 서브시스템 (D1/D2 수용체, 5-HT2A/2C, CRH/ACTH, 히스타민, 아데노신, 엔도르핀, 아난다마이드, mACh/nACh, BDNF)
- 총 21개 노드의 상호작용 네트워크

### 5.2 Φ 근사 측정
- `/state`에 `phi` 필드 추가
- 시스템 복잡도를 수치로 추적
